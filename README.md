# Trilha JS Developer - Pokedex
🔴 Pokédex

Uma Pokédex desenvolvida com HTML, CSS e JavaScript, utilizando a PokéAPI para buscar e exibir informações dos Pokémon de forma dinâmica.

O projeto foi desenvolvido como parte dos desafios de desenvolvimento web da DIO (Digital Innovation One), com o objetivo de praticar conceitos fundamentais de JavaScript, consumo de API REST, manipulação do DOM, responsividade e organização de projetos.
